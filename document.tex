\section{緒言}
%書くで　緒言は最後やな
災害大国である日本では，不整地環境で活動可能な移動ロボットの需要が高い．
そのため，設計段階から多様なアプローチが考えられてきた．
代表的な例として，車輪や履帯等の移動機構の併用および合体
\cite{cite:Quince,cite:TITANXX,cite:trackwalker,cite:iRobotPackBot}，
湾曲可能な履帯や直進以外も可能な車輪等の移動機構の改良
\cite{cite:DFC,cite:Mecanum_wheel}，
脚移動や蠕動移動等
\cite{cite:asterisk,cite:harvestman_robot,cite:i_centipod_aqua,cite:K3,cite:six_legged_robot}
の多様なアプローチが取られている．
これらの先行研究における不整地走破性能の評価方法は，段差の高さや斜度，間隙の長さなどのスケールを用いた指標や
\cite{cite:TITANXX,cite:DFC,cite:six_legged_robot,cite:ro-ba}，
ロボットフィールドや模擬の災害現場といった特定の環境内における走行速度や，走破可否といった走行性能
\cite{cite:Quince,cite:trackwalker,cite:i_centipod_aqua}
を指標として検証されてきた．
しかしながら，このような評価方法では個別の状況・条件における性能しか比較できず，実際の現場が同様の環境であるとは限らない．
つまり，走行性能の評価・比較において重要なのは，個別の状況においての走行性能を知ることではなく，
様々な状況・環境に展開して走行性能を捉えることである．
そこで本研究では，走行性能を様々な地形環境やロボットに依存せずに評価できる手法の構築を目指す．
具体的には，不整地の路面形状の凹凸を空間的な波形として考え，その不整地における走行性能を波形の振幅と周波数に対する応答として捉える
(Fig.~\ref{fig:concept})．

前報\cite{cite:myproceedings}では，
車両の設計を固定した四輪車を複数の振幅条件の正弦波地形上を走行させ，周波数領域で走行性能を評価することが有効であることをシミュレーション環境で確認しており，
地形の振幅という環境要因における走行性能の検証は既に行っている．
このため，車両の設計パラメータによる走行性能の変化を確認することを次の目的としており，特に注目しているのは地形に接する部分である車輪径である．
このような理由から本稿では，
四輪車の設計パラメータが正弦波地形上における走行性能に及ぼす影響を調査し，車輪径と走行速度の関係性について検証した結果について述べる．

\subsection{評価方法}
%ここにはシミュレーションでやる走行性能の評価方法について書いていくぞ
%まずはロボメックでやった方法についての話をする

本節では，前報で構築した走行性能評価手法について説明する．
Fig.~\ref{fig:simallimage}に示すのは，本シミュレーションの全体構成である．
Fig.~\ref{fig:simimage}は概念図であり，Fig.~\ref{fig:simscreenshot}は実際のシミュレーションの様子である．
%シミュレーションのモデル化について話すとよさそう
%まずはsim全体で定義した部分を話します
鉛直方向を$z$~[m]，走行方向を$x$~[m]，車両高さを$H$~[m]，車両長さを$L$~[m]，車輪間の距離を$W$~[m]，車輪直径を$D$~[m]，地形の振幅を$A$~[m]，地形の波長を$\lambda$~[m]，車輪に与える角速度を$\omega$~[rad/s]，車両重心のピッチ角を$\theta$~[rad]とする．
%simはどのように動くのかを説明するとよさげ
車両はFig.~\ref{fig:simimage}の正弦波地形に侵入する前の直線状の加速レーンの上に静止状態で配置し，車輪にトルク$T$を与えて正弦波形状の地形へ侵入させる．地形はその周波数および振幅を段階的に変化させることで，様々な地形条件を再現可能にする．
%空間周波数の定義を説明しておく（簡単に
このとき，地形の周波数は空間周波数$f$~[cycles/m]，波長$\lambda$~[m]，振幅$A$~[m]の関係式$f=1/\lambda$~[cycles/m]を用いて表される．
%simで何を確認したいんじゃ？
各地形条件下における車両の挙動を確認するために，地形の各周波数毎の車両の挙動として各周波数における進行方向および鉛直方向の速度$V_{\mathit{x}}$および$V_{\mathit{z}}$，加速度$a_{\mathit{x}}$および$a_{\mathit{z}}$，ピッチ方向の角速度$\omega_{\mathit{p}}$，角加速度$\alpha_{\mathit{p}}$の平均値を計測する．
%あと追加でsimの限定した条件も話しとく
%二次元的にまずはやってみたんだぜ
また，車両の基礎的な挙動を確認するために，$xz$平面で車両を矢状面に固定し，車両のヨー軸およびロール軸の回転要素を考慮せず，地形の波形も$xz$平面内で変化する正弦波形状とした．

\section{車輪径の変化による走行速度・到達距離の結果}
\label{sec:result}
%ここには過渡応答的になってしまっていた（トルクが時間で強くなりすぎる）時のsim結果を載せるぞ
本節では，Table.~\ref{table:conditions}に示すような車輪径$D$を$D$ = 0.125~m, 0.250~m, 0.375~m, 0.50~m, 0.625~m, 0.750~m, 0.875~mの7水準で変化させた，それぞれの空間周波数地形における走行結果を示す．

%結果について話す
計測したデータは各空間周波数における進行方向速度$V_{\mathit{x}}$，最終到達距離$X$である．
Fig.~\ref{fig:distance}は車両の最終到達距離$X$を示したものである．
いずれの車輪径においても，$f$ = 1~cycle/m付近において到達距離が落ち込み2~m程度となっている．
車輪径が大きくなるほど$f$が大きくなったときの到達距離の回復が早く，$f$ = 0.2~cycle/m程度の低周波帯域では到達距離の落ち込みが遅くなる．
いずれの車輪径においても，$f$ = 0.3～0.5~cycle/m付近で一時的に到達距離が落ち込み，$f$ = 0.6～0.9~cycle/m付近で回復している．
$f$ = 0.2~cycle/m低周波帯域では到達距離の上下が激しく，車輪径が小さいほどその変動は激しい．
$D$ = 0.125~mでは距離の変動が激しく，安定していない．

Fig.~\ref{fig:velocicty}は車両の進行方向の速度$V_x$を示したものである．
$D$ = 0.125，0.250~mでは速度の変動が激しく，安定していない．
いずれの車輪径においても，低周波帯域から$f$ = 1~cycle/mに近づくにつれて速度が低下し，$f$ = 4～6~cycle/mにかけて速度が回復傾向にある．
車輪径にかかわらず，$f$ = 0.4～0.6~cycle/mにかけて一時的な速度の落ち込みがある．
高周波帯域では，いずれの車輪径も$f$ = 1~cycle/m付近における速度よりも遅い．
車輪径が大きくなるにつれて，$f$ = 1~cycle/mから速度が回復するのが早い傾向にある．
$D$ = 0.125，0.250~mを除いて，車輪径が大きいほど走行速度は遅くなる．

Fig.~\ref{fig:distance}とFig.~\ref{fig:velocicty}の二つのグラフを踏まえてみれば，$f$ = 0.8～0.9~cycle/m付近では走行速度は遅いものの$D$ = 0.125, 0.250~mを除いて最高距離に到達できているが，$f$ = 0.4~cycle/m付近ではいずれの車輪径も最高距離に到達できていない．
$D$ = 0.875~mのとき，$f$ = 2~cycle/m付近で到達距離が35~m付近まで回復しており，このとき，速度は回復途中になっている．
$f$ = 0.4～0.5~cycle/m付近では，車輪径が大きいほど走行速度が一時的に落ち込んでおり，そのタイミングで到達距離が大きく低下している．
車輪径が大きいほど，$f$ = 2～4~cycle/m付近では速度が遅くとも走行距離が伸びているということがわかる．

\subsection{考察}
\label{sec:discussion}
距離，速度ともに$f$ = 1～3,4~cycle/m程度の間で低下する理由はホイールベースにあると考えられる．ホイールベースと波長の長さが一致するタイミングは$f$ = 2~cycle/mのときであり，先ほどの$f$の値の中間地点に近い．つまり，$f$ = 2~cycle/m前後のタイミングでは，走行が困難である．
$f$ = 0.4～0.5~m付近で車輪径が大きいほど走行速度が一時的に落ち込んでおり，そのタイミングで到達距離が大きく低下しているのは，車輪に一定トルクを与えている影響だと考えられる．
一定トルクでは，車輪径が小さいほど推進力を得やすく大きいほど得にくいため，坂道を上る力が十分でなかったと考えられる．
また，$D$ = 0.125, 0.250~mの小さい車輪径では，車輪径が小さいために大きな推進力を得てしまっていると考えられる．Fig.~\ref{fig:velocicty}の平均速度が大きく変動しているのは，強すぎる推進力の影響で車両が宙に浮く，ひっくり返るといった原因が考えられる．

Fig.~\ref{fig:contact}は車輪径の大きさによる車輪の曲率の変化と地形に対する接触位置を示したものである．
車輪径が大きいほど，車輪の外側の曲率が小さくなって直線に近づいていくことで，地形の谷に車輪が嵌ることが無くなり，山から山に接触位置が移動するようになり，速度が回復していくと考えられる．
また，地形の波長が小さくなっていくことによって，地形に対する車輪の接触位置同士が近づいていき，走行速度は車輪径によらず高い周波数では回復していくことがわかる．

Fig.~\ref{fig:Smallwheel}は車輪径が小さい車両において，地形の波長がホイールベースよりも細かくなった時に車体の底面が接触する現象を示したものである．
地形の振幅は$A$ = 0.1~mのため，山から谷までの距離は0.2~mである．
$D$ = 0.125, 0.250~mの車輪径では車体底面と地形までの距離が0.2~mよりも短くなってしまい，車体の底面に地形が接触することになる．
これによって，ホイールベース間に複数の波長の周期が現れるときに走行できなくなり，$D$ = 0.125, 0.250~mの車輪径では他車輪径と似たような速度の回復が現れなかったと考えられる．
しかしながら，$D$ = 0.375~mの車輪径においても，同様に車体底面からの距離は0.2~mを下回っているものの，他車輪径と同様の速度回復を確認できる．
これは，前述した車輪径が大きいことによる接触位置の変化によるものと推察でき，車輪が谷に完全に嵌らなかったおかげで車体底面が地形の山に接触しなかったと考えられる．

結果から，
一定トルクで四輪車を走行させた場合，走行速度は車輪径が大きくなるほど遅くなることは当然である．
地形を離れて空転しない，適切なトルクを受けられる車輪径においては，3か所の走行可能な周波数帯域があることがわかった．
この周波数帯域では，走行速度が速い箇所と遅い箇所の2種類があることが分かった．
車輪径が変化によって$f$ = 1～3~cycle/m付近での速度低下の大きさは変わらないことが分かった．
車輪径と波長の大きさの関係が車両の走行可否に影響を与えていることが分かった．

\section{現在の取り組み}
\subsection{定常状態における走行性能の評価}
%ここは今やってる（SIで発表予定）の進捗を載せたい
%過渡応答的になってしまっていた（トルクが時間で強くなりすぎる）前回の結果を踏まえて，定常状態の速度で波に侵入するようなシミュレーションを行うように変更した．
\ref{sec:result}章で述べた結果は，車輪に一定トルクを与えて走行させた影響で時間が進むにつれて車輪の回転速度が上がり，走行速度が上がってしまう過渡応答的な挙動を示していた．
そこで定常状態での結果を観察するために，車輪に一定トルクを与える方法は変えずに，車輪に与えたトルクにtable\ref{table:conditions}に示した車軸の抵抗を加えることで走行速度が上昇し続けることを抑制した．
この車軸の抵抗とは，車輪の角速度に比例する粘性抵抗のことである．
また，シミュレーション開始前に各車輪径毎に一度平面を最低10~s走行させ，2~s毎に走行速度のばらつきが1~％未満になったかを確認するようにした．加えて定常速度を記録し，この定常速度を初速として車両に与えて正弦波地形に侵入させるように変更した．

\section{結言}
%--------------------------------------------------------------------
本研究では，従来のように個別の不整地への走行性能を評価するのではなく，様々な不整地に対する走行性能を評価する指標を提案した．具体的な手法は，地形を空間的な波として表現し，その周波数成分を変化させた地形における移動ロボットの走行性能を，応答特性として評価するというものである．
また，本手法の有効性を検証するために，物理シミュレーションを用いて検証を行った．本研究の主な成果として，地形の空間周波数$ｆ$とホイールベース$Ｗ$の関係が，四輪車の走破性に大きな影響を与えることが分かった．
現在は，車両のパラメータを変更した場合の四輪車の走行シミュレーションを行うための準備を行っている段階である．

今後は，車両のパラメータを一つずつ変更した場合の走破性の変化を調べるとともに，車両全体の大きさを変えた場合の走破性の変化も調べる予定である．
また，この2つのシミュレーションの結果を元に，車輪の数を増やす，車輪の形状を変える，違う移動機構に変える等の方法で走破性を高めることはできるのかを調べる予定である．
これらのシミュレーションを行った後，基礎的な正弦波地形における走破性の重ね合わせによって，不整地環境における走破性がわかるかどうかを調べる予定である．
前述した過程における結果を元に，未知環境における移動ロボットの走破性が予測可能かを検討する．
