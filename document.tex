\section{緒言}
%スケールフリーの走破性評価軸の緒言がこんな感じ
%研究の背景
災害大国である日本では，不整地環境で活動可能な小型移動ロボットの需要が高い．
%災害大国である日本では，地震や台風などの自然災害の影響で人間が立ち入ることが極めて困難な環境が多く存在する．このような凹凸の多い不整地や狭隘な環境における探索，調査，復興作業等を人間の代わりに行うために，小型移動ロボットの需要が1995年の阪神淡路大震災以降高まっている．加えて，2011年の東日本大震災および福島第一原発事故以降，有毒ガスや放射線の影響で人間が立ち入ることができない環境でも活動可能な小型移動ロボットの需要が更に高まった．
%こんな移動機構をもつロボットが多くある
このような
%環境で活動する小型
移動ロボットは，複雑な環境での走破性を向上させるために，設計段階から多様なアプローチが考えられてきた．
代表的な例として，複数の移動機構の併用および合体
\cite{Quince,TITANXX,trackwalker,iRobotPackBot}，
新たな移動機構の開発
\cite{DFC,Mecanum_wheel}，
生物に着想を得た移動機構の検証
\cite{asterisk,harvestman_robot,i_centipod_aqua,K3,six_legged_robot}
等が挙げられる．
しかしながら，これらの移動ロボットには，ロボット同士での性能の比較が難しいという課題がある．
その要因の一つとして，移動ロボットの不整地走破性能における一般的な指標が存在しないことが挙げられる．

%先行研究での課題
先行研究における不整地走破性能の評価方法は，段差の高さや斜度，間隙の長さなどのスケールを用いた指標や
\cite{TITANXX,DFC,six_legged_robot,ro-ba}，
ロボットフィールドや実際の災害現場のような特定の環境内における速度や加速度，走破可否といった性能によって検証されてきた
\cite{Quince,trackwalker,i_centipod_aqua}．
%ロボットたちの性能評価の課題点とは
%いままでは，段差やら斜度のスケールや災害現場を再現した特定の環境における走破可否から検証されてる
%でも，スケール感覚が把握しにくくて，実際の現場でどう動くかは未知数だった
このような方法では，人間サイズのロボットが10~cmの段差を乗り越えた場合と，10~cmサイズのロボットが10~cmの段差を乗り越えた場合では，両者の差異を区別できない．
つまり，これらの手法による評価はロボットの大きさに依存するため，大きさの異なるロボット間での性能比較には適していない．
加えて，特定の環境における走破性能しか評価できないため，実際の現場の不整地における走破性能を予測することも困難である．

%そこで，新しい性能評価ができるようになるとおもしろい
そこで本研究では，様々な地形や環境における走行性能をロボットの大きさに依存せずに評価できる手法の構築を目指す．
本手法は，不整地を周波数表現することで移動ロボットのスケールと地形のスケールの関係を捉えるというものである(Fig.~\ref{fig:概要図})．
従来のスケールによる個別の評価や時間領域での評価ではなく，地形を空間的な波として捉え，その周波数成分を変化させた地形の上を走行させたときの移動ロボットの走行性能を，応答特性として評価する．
%sin波で見れば移動ロボットの走行性能を一般化できるのではないかと考えた．
このように，移動ロボットの走破性を周波数領域で評価することで，様々な地形に応じた走行性能を評価できると考えた．

%この手法によってなんで従来のロボットのスケール依存という課題が解決できるのか？
段差や斜度，間隙の長さ等の地形は，地形が連続であると仮定した場合には，sin波の重ね合わせとして表現可能である．
つまり，sin波で表現した地形の上を走らせれば，現在の段差や斜度，間隙の長さなどの要素を網羅していることになる．
% また，重ね合わせによって地形を表現できるだけではなく，sin波の波長を変更するだけでも様々な地形条件に似た要素が表現できる．
% 例として，四輪車をsin波の地形を走らせるとき，振幅が十分大きいときを考える．
% 地形の波長がホイール径より少し大きい場合は車輪が波長の間に完全に収まり走行できないことが予想される．
% 地形の波長が車体よりも大きい場合では，車体が下に落下することが予想される．
% これは，間隙の長さによる走破性と同じになるだろう．
加えて，走破性が敏感に反応する周波数帯域が存在することが分かれば，車両と地形のスケール関係を捉えることができる．
このことから，本手法を用いることで従来のロボットのスケール依存の問題を解決できると考えた．

%この手法を使ってなにか面白いことができるか？
%未知環境における走破性を予測するアプローチを考えた
% この手法を用いることで，未知環境における走破性能を予測することも期待できる．
% 災害現場は未知環境であり，建物の倒壊等の影響で環境が刻々と変化する．このため，観測するまで地形の形状がわからず，事前に移動ロボットの走破性能を予測することはできない．
% 未知の不整地を十分滑らかで連続した波であるとして，フーリエ変換の考え方を応用してそれぞれの周波数帯のsin波地形に分解できると仮定する．
% このとき，前述したsin波形状の地形の上を走らせて周波数の変化と走破性能の関係の考え方から，この分解した各sin波地形における走破性能を個別に調査して重ね合わせることで，未知の不整地における走破性能を予測できる可能性がある
% %（未知環境を分解できると仮定し，走破性の重ね合わせで表現する→イメージ図を貼る）

\section{地形の振幅を変更させた場合の四輪車走行シミュレーション}

%シミュレーションの構想や意図，仮説について書く
%具体的には，なんのためにどんなシミュレーションをするのか，についてかこう
%まず今までの流れのおさらい
本研究では，地形を空間的な波として表現し，その周波数成分を変化させた地形における移動ロボットの走行性能を，応答特性として評価する手法をシミュレーションを用いて検証する．
%シミュレーションの目的は？
「地形を空間的な波として表現する」とは，本来1秒あたりに振動が繰り返される回数で表現される「周波数」という概念を，1~mあたりに波が繰り返される回数，「空間周波数」として表現することである．
この空間周波数によって不整地を周期的な波として捉えられると仮定すれば，フーリエ級数による分解・重ね合わせの考え方を用いて，複雑な不整地を単純な正弦波に分解して考えることが可能になると考えた．
% この空間周波数を用いて，正弦波状の地形を作成する．
% このとき，古典制御におけるボード線図のように，移動ロボットを正弦波状の地形上で走行させたときの走行速度やピッチ方向の変化等の走行性能を縦軸に，地形の空間周波数を横軸にとったグラフとして表現する．
%ここからの文章が微妙いいの考えたい
これにより，ある一定の車両条件において，ある空間周波数帯域では良好な走行が可能，ある空間周波数帯域では不安定な走行になる，といったように地形の得手不得手を評価することが可能になる．
シミュレーション実験では，このグラフを地形の振幅や，移動ロボットの実験条件を変更した場合について作成し，この手法の有効性を検証する．

\subsection{シミュレーションの条件および方法}

Fig.~\ref{fig:まとめ図}に示すのは，本シミュレーションの全体構成である．
Fig.~\ref{fig:simのイメージ図}はシミュレーションの概念図であり，Fig.~\ref{fig:simスクショ}は実際のシミュレーションの様子である．
シミュレーションでは，実装が容易かつ基本的な移動機構である四輪車を，直方体および円柱形状で簡易的にモデル化した．
鉛直方向を$z$~[m]，走行方向を$x$~[m]，車両高さを$H$~[m]，車両長さを$L$~[m]，車輪間の距離を$W$~[m]，車輪直径を$D$~[m]，地形の振幅を$A$~[m]，地形の波長を$\lambda$~[m]，車輪に与える角速度を$\omega$~[rad/s]，車両重心のピッチ角を$\theta$~[rad]とする．
%まず，基本的な移動機構として四輪車を直方体および円柱形状で簡易的にモデル化した．
車両はFig.~\ref{fig:simのイメージ図}に示す直線状の地形とした加速レーンの上に静止状態で配置し，車輪に角速度$\omega$を与え，所定の速度まで加速された後，正弦波形状の地形へ進入する．地形はその周波数および振幅を段階的に変化させることで，様々な地形条件のシミュレーションを可能にする．
このとき，地形の周波数は空間周波数$f$~[cycles/m]，波長$\lambda$~[m]，振幅$A$~[m]の関係式$f=1/\lambda$~[cycles/m]を用いて表される．
%これは，1~mあたりの波長の数を示すものであり，波長が短いほど高周波数となる．
各地形条件下で車両の挙動を確認するために，地形の各周波数毎の車両の挙動として，各周波数における進行方向および鉛直方向の速度$V_{\mathit{x}}$および$V_{\mathit{z}}$，加速度$a_{\mathit{x}}$および$a_{\mathit{z}}$，ピッチ方向の角速度$\omega_{\mathit{p}}$，角加速度$\alpha_{\mathit{p}}$の平均値を計測した．
%これを振幅ごとに繰り返し，周波数および振幅の変化が走行性能に与える影響を調査する．
また，本シミュレーションでは車両の基礎的な挙動を確認するために，$xz$平面で車両を矢状面に固定し，車両のヨー軸およびロール軸の回転要素を考慮せず，地形の波形もxz平面内で変化する正弦波形状とした．

\subsection{シミュレーションの条件}
Tabel~\ref{table:Experiment_conditions_amplitude}に示すのは，本シミュレーションにおける四輪車のパラメータである．
車両の各パラメータは小型移動ロボットを想定した値に設定した．
シミュレーション時間は10秒間とし，静止状態から車輪に角速度$\omega_{\mathrm{max}}$を与えて加速走行させる．車輪の角速度と角加速度には上限を設けており，車輪の角速度が目標値に達した後は一定速度で走行する．
また，車両が一定速度に達するまでの加速区間として3.90~mの加速レーンを設けた．
%この時，四輪車の進行方向と鉛直方向の，速度および加速度，ピッチ角の角速度および角加速度を計測する．
これにより，変化させた地形の振幅と波長に対して，
%四輪車の走行可否，
鉛直方向の揺動，前後方向の速度，ピッチ角の挙動を評価する．

% 本シミュレーションでは，物理シミュレーションソフト「MuJoCo」(Multi-Joint dynamics with Contact)\cite{mujoco}を用いた．
%「MuJoCo」は，高速かつ高精度な物理シミュレーションを実現するために設計されたソフトウェアであり，ロボット工学やバイオメカニクスの分野で広く利用されている．
%特にロボットの関節部や物体同士の接触に関するシミュレーションに優れている点が特徴である．この特徴から，地形と車輪の接触や，車輪の回転運動に対する計算速度と精度が重要な本研究のシミュレーションに適していると考えた．

Fig.~\ref{fig:discussion1}に，振幅$A$ = 0.09~mにおける進行方向の速度Vxと空間周波数fの関係，および$f$ = $10^{-1}$, $10^0$, $10^{0.3}$, $10^1$~cycle/mのときのシミュレーションのスナップショットを示す．
%Fig.~\ref{fig:discussion1}は，振幅$A$ = 0.09~mのときの進行方向の速度のグラフ，空間周波数$f$ = 0.1, 1, 2, 10~cycle/mのときのシミュレーションの様子，走行速度が大きく低下した領域を赤丸で示したものである．
速度が大きく低下する周波数帯域(赤丸)は，ホイールベース(前輪中心と後輪中心の距離)と地形の実波長が近くなる$f$ = $10^0$～$10^1$~cycle/m付近になっている．
これはホイールベースと地形の実波長が近くなることで，前後の車輪が同時に段差に乗り上げることになり，車体が大きく揺さぶられるためと考えられる．
また，空間周波数$f$ = $10^1$~cycle/m付近からは速度が回復している．
%これは，車両の車輪径に対して十分に地形の波長が細かければ，直線とみなして走行できているためである．
これは，車両の車輪径に対して十分に地形の波長が短ければ，車輪が地形の凹凸に追従しなくなり，平面における走行に近い状態になるためである．
このことから，車両の走行速度が大きく低下する現象には車両のホイールベースが影響しており，走行速度が回復し始める現象には車輪径が影響していると考えられる．
よって，四輪車を対象とした場合は，ホイールベースと車輪径の両方が走行速度に影響を与える重要なパラメータであることが分かった．

しかしながら，実際の設計では，車両に対して地形から走りやすくなるように合わせに来てくれるわけではないため，移動ロボットのパラメータを変更したときに，どのように走破性が変化するかを知ることが重要である．
%次にやりたい，車両パラメータを変更したシミュレーションのイメージ
そのために，本研究の次の段階として，(table.~\ref{table:Experiment_conditions_vehicle_parameter})における車両パラメータ$W$, $L$, $D$, $M$, $m$, $W$, $\omega_{\mathit{max}}$, $\alpha_{\mathit{rmax}}$を一つずつ変更していった場合に，周波数と振幅を固定した地形上で四輪車走行シミュレーションを行う．
%全部一気に大きくしたらどうなるか，も見てみる
加えて，車両全体の大きさを変えた場合のシミュレーションも行う予定である
(Fig.~\ref{fig:車両パラメータ変更でのイメージ図})．
%何を計測するんだ
各条件下で確認する車両の挙動は，前述したシミュレーションと比較しやすいよう同様に，
地形の各周波数における進行方向および鉛直方向の速度$V_{\mathit{x}}$および$V_{\mathit{z}}$，加速度$a_{\mathit{x}}$および$a_{\mathit{z}}$，ピッチ方向の角速度$\omega_{\mathit{p}}$，角加速度$\alpha_{\mathit{p}}$の平均値を計測する．
現在は車両のパラメータを各々変更するためのコードの作成を行っている段階である．
このシミュレーションの結果から，地形の空間周波数$f$と車両の各パラメータの関係が四輪車の走破性に与える影響を調べる．

\section{まとめと今後の展望}
%--------------------------------------------------------------------
本研究では，従来のように個別の不整地への走行性能を評価するのではなく，様々な不整地に対する走行性能を評価する指標を提案した．具体的な手法は，地形を空間的な波として表現し，その周波数成分を変化させた地形における移動ロボットの走行性能を，応答特性として評価するというものである．
また，本手法の有効性を検証するために，物理シミュレーションを用いて検証を行った．本研究の主な成果として，地形の空間周波数$ｆ$とホイールベース$Ｗ$の関係が，四輪車の走破性に大きな影響を与えることが分かった．
現在は，車両のパラメータを変更した場合の四輪車の走行シミュレーションを行うための準備を行っている段階である．

今後は，車両のパラメータを一つずつ変更した場合の走破性の変化を調べるとともに，車両全体の大きさを変えた場合の走破性の変化も調べる予定である．
また，この2つのシミュレーションの結果を元に，車輪の数を増やす，車輪の形状を変える，違う移動機構に変える等の方法で走破性を高めることはできるのかを調べる予定である．
これらのシミュレーションを行った後，未知環境における移動ロボットの走破性を予測することを目標とする．
